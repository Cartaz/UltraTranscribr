# Screenshot e verifiche QML

`qml-comparison.png` mostra sette viste originali/QML. `qml-verification.zip` contiene tutte le 22 coppie, geometrie e report: estrarre il pacchetto e aprire `comparison.html`. `metrics.json` contiene le differenze senza maschere. `runtime-smoke.json` descrive l'avvio completo isolato; `dependency-audit.json` riguarda le sole distribuzioni installate.

I dati non certificano parità pixel perfect o inferenza hardware. Dettagli e comandi: [audit](../../docs/QML_AUDIT_2026-10-01.md).
