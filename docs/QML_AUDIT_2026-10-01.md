# Audit e porting QML — 1 ottobre 2026

## Esito e limiti di accettazione

Le sei viste e l'overlay Dettatura sono portati a Qt Quick/QML, con QApplication per tray, clipboard e dialoghi nativi. La UI delega ad ApplicationService attraverso adapter separati e modelli Qt. Il programma non carica WebEngine né WebChannel.

La suite locale passa **481 test**, rispetto ai **455** del commit originale `8cef0dc7385bcba82cb1aa41b7c04238ea208229`, verificato separatamente. Il composition root `main.main()` è stato nuovamente avviato dopo l'affinamento visivo, sono state aperte tutte le viste e lo shutdown è terminato con codice **0**, nessun thread Python residuo e nessun modulo WebEngine/WebChannel caricato.

**La parità pixel perfect non è raggiunta.** I confronti conservano differenze di rasterizzazione dei testi, ombre, controlli audio/editor e alcuni allineamenti. Il branch resta una proposta in draft: questi risultati non autorizzano a dichiarare identità visiva o funzionamento completo su hardware reale.

L'ambiente non ha GPU Intel SYCL, whisper-server compilato, modelli di inferenza, server audio PulseAudio/PipeWire o sessione KDE/Wayland con portali e tray. Il fixture sostituisce esclusivamente il rilevamento GPU per aprire la UI; dati e impostazioni sono isolati. Non è stato introdotto alcun fallback CPU nel programma. Inferenza, Demucs, Community-1/XPU, hotkey globali, inserimento del testo e ripristino del routing richiedono verifica sul desktop di destinazione.

## Audit tecnico

- **Confini:** main compone e chiude; core possiede backend, code, worker, store e routing; gli adapter UI usano il service pubblico. Il catalogo eventi è separato dal bridge storico. I modelli espongono copie dei record e aggiornamenti incrementali.
- **Concorrenza:** segnali queued dal worker alla GUI, task con proprietario esplicito, generazioni contro risultati obsoleti, bozze persistenti in Python, nessuna scrittura su disco nel delegate QML. Bootstrap e ripristino geometria rimangono letture piccole iniziali; le operazioni interattive su cronologia e impostazioni passano ai worker.
- **Persistenza:** invariati store canonici, raw transcript e formati TXT/SRT/VTT. Salvataggi atomic/thread-safe del core coperti dalla suite precedente e nuove prove con file reali temporanei. I dialoghi di export e file selection sono nativi.
- **Sicurezza:** nessun nuovo shell=True/eval/pickle; URL remoti rifiutati dal drop, testo mostrato letteralmente. Backend HTTP e validazione percorsi restano nel core. Queste verifiche non sono una certificazione di sicurezza né un penetration test.
- **Dipendenze:** PySide6 minimo 6.11 per RectangularShadow e QML usati dal port. Ambiente verificato con Python 3.12.14 e PySide6 6.11.2. `uv pip check` passa. pip-audit ha segnalato il pip locale 25.0.1; aggiornato a 26.2.1, nuova scansione delle 33 distribuzioni installate: zero vulnerabilità note. L'installer e CI già aggiornano pip quando installano le dipendenze. Lo stack XPU/native non installato non è incluso in questa scansione.
- **Installazione:** bash -n passa; non è stata eseguita una build/installazione Intel oneAPI completa. Non è stato cambiato il vincolo GPU SYCL/XPU.
- **Memoria:** il campione dello smoke test contiene RSS/PSS in runtime-smoke.json; è un singolo campione dopo navigazione, senza inferenza, nell'ambiente virtuale. Non dimostra un miglioramento percentuale o un limite massimo su desktop reale.
- **CI:** aggiunti renderer software per i test funzionali e qmllint. I controlli JS rimangono per il riferimento precedente. I test su HTML/JS verificano quel riferimento, mentre test_qml_runtime.py e il nuovo smoke test esercitano la UI QML reale.

Nel secondo affinamento visivo sono stati riallineati al riferimento: player scuro con icone e tempo mm:ss, pulsanti browser della revisione, larghezza dei selettori speaker, interlinea, altezze di campi/pulsanti, navigazione e scrollbar. Le ombre interne usano ora copertura Gaussiana approssimata e compositing CSS anziché sommare un bordo chiaro; quelle esterne sono più diffuse. Il player mantiene Qt Multimedia: il suo menu non è il menu nativo Chromium. Non viene dichiarata identità di rasterizzazione.

`ui/web/` e `ui/bridge.py` sono conservati come riferimento per screenshot e contratti precedenti. Non vengono importati dal percorso di esecuzione della UI QML.

## Riproduzione

```bash
python -m pip install -r requirements.txt pytest Pillow
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software pytest -q
pyside6-qmllint --unqualified info -I ui/qml ui/qml/*.qml
bash -n install.sh
python -m compileall -q main.py config core ui tests tools
# In una sessione grafica o con xvfb-run:
python tools/capture_ui.py --output tests/visual/after
python tools/capture_ui.py --populated --output tests/visual/populated-after
QT_SCALE_FACTOR=2 python tools/capture_ui.py --output tests/visual/after
python tools/smoke_app.py --output tests/visual/runtime-smoke.json
# Per baseline: --frontend web --source-root /percorso/worktree-baseline
# Dopo entrambe le catture e la scansione dipendenze:
python tools/compare_ui.py
```

Lo shader compilato è versionato; sorgente GLSL incluso. Rigenerazione: `pyside6-qsb --qt6 -o ui/qml/shaders/inset.frag.qsb ui/qml/shaders/inset.frag`.
